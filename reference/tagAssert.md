# Assert that a tag has specified properties

Assert that a tag has specified properties

## Usage

``` r
tagAssert(tag, type = NULL, class = NULL, allowUI = TRUE)
```

## Arguments

- tag:

  A tag object.

- type:

  The type of a tag, like "div", "a", "span".

- class:

  An HTML class.

- allowUI:

  If TRUE (the default), allow dynamic outputs generated by
  [`uiOutput`](https://rdrr.io/pkg/shiny/man/htmlOutput.html) or
  [`htmlOutput`](https://rdrr.io/pkg/shiny/man/htmlOutput.html). When a
  dynamic output is provided, `tagAssert` won't try to validate the the
  contents.
