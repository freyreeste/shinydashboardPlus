# Valid statuses extra

These status strings correspond to colors as defined in adminLTE extra
colors. Although the colors can vary depending on the particular CSS
selector, they generally appear as follows:

## Details

- `primary` Blue (sometimes dark blue)

- `success` Green

- `info` Blue

- `warning` Orange

- `danger` Red

- `navy` Dark Grey/Blue

- `teal` Blue/Green

- `orange` Orange

- `purple` Purple

- `maroon` Pink

- `black` Black
